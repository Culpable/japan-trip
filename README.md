# Japan Trip 2026

Interactive itinerary for Hong Kong, Shenzhen and Japan from 1–15 August 2026.

The site is published through GitHub Pages from `index.html` on the `main` branch.

The static site includes a 45-day browser-local access gate, automatic trip-day state, hotel and booking utilities, one-click local names for every hotel, transit route, itinerary moment and confirmed booking, per-day maps and weather links, and offline PWA caching. Local text uses Simplified Chinese in mainland China, Traditional Chinese in Hong Kong and Japanese in Japan. The access gate prevents casual viewing but is not a substitute for server-side authentication because GitHub Pages serves public static source files.
